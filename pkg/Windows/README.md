# Windows package output

This directory is the output location for CI-generated Windows packages.

GitHub Actions creates:

- `WindowsOptimizerSetup.exe` — the graphical Windows installer.
- `WindowsOptimizer-win-x64.zip` — portable self-contained x64 build.
- `SHA256SUMS.txt` — SHA-256 checksums.

The binary installer is intentionally generated by the Windows CI runner rather than committed to source control.

To build it manually in GitHub Actions, run **Build Windows installer** from the Actions tab.
