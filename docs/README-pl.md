# Windows Optimizer v1 — Polski

Narzędzie do optymalizacji Windows 11 dla komputerów stacjonarnych i laptopów: bezpieczne odchudzanie systemu, profile wydajności, monitoring sprzętu, czyszczenie RAM i biblioteka programów.

Przed zmianami systemowymi przeczytaj `SAFETY.md`. Uprawnienia administratora są wymagane tylko wtedy, gdy są potrzebne.
