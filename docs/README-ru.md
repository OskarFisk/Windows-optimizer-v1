# Windows Optimizer v1 — Русский

Инструмент оптимизации Windows 11 для настольных ПК и ноутбуков: безопасная очистка системы, профили производительности, мониторинг оборудования, очистка RAM и библиотека программ.

Перед изменениями системы прочитайте `SAFETY.md`. Права администратора запрашиваются только для операций, которым они действительно нужны.
