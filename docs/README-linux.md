# Linux

Windows Optimizer v1 supports Linux through distribution-specific adapters.

## Supported targets

Ubuntu, Debian, Linux Mint, Fedora, RHEL-compatible systems, Arch-based systems, openSUSE and compatible SteamOS desktop environments are planned targets.

## Important

Linux distributions differ in package managers, services, desktop environments and permissions. The optimizer detects the platform and never applies Windows-specific operations to Linux.

Hardware monitoring and cleanup are preferred first features. Debloating is distribution-specific and must be previewed before applying changes.

See [PORTABILITY.md](PORTABILITY.md) for the architecture and feature matrix.
