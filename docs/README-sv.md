# Windows Optimizer v1 — Svenska

Ett Windows 11-verktyg för stationära datorer och laptops med säker debloat, optimeringsprofiler, övervakning, RAM-rensning och ett kategoriserat programbibliotek.

Läs `SAFETY.md` innan systemändringar. Administratörsbehörighet begärs bara när en åtgärd behöver det.
