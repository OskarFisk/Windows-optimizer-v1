# Programs Library

The library is designed as a categorized catalog, not as a piracy/repackaging system.

## Categories
- Browsers
- Gaming
- Game launchers
- Graphics and video
- Audio
- Communication
- Productivity
- Development
- Compression and utilities
- Hardware monitoring
- GPU tuning
- CPU tuning
- Virtualization / Android
- Drivers and vendor utilities
- Benchmarking
- Security

## Featured hardware tools
The catalog should include official entries for:
- MSI Afterburner
- AMD Ryzen Master
- Intel performance/tuning utilities where supported
- AMD Radeon software and tuning utilities
- NVIDIA App / supported NVIDIA utilities
- BlueStacks

The application should show vendor, purpose, compatibility, official source, and whether administrator rights are normally required.

## Installation policy
Prefer official installers or documented package-manager commands. Never download and execute an arbitrary executable merely because its URL appears in a catalog entry. Validate HTTPS sources, show the source to the user, and keep installation actions explicit.

## Ninite
Ninite can be offered as a convenience integration where appropriate. The app should link to the official Ninite service rather than re-hosting its installers.
