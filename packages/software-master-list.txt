64. IMPORTANT SAFETY NOTES
--------------------------
Do not run multiple debloaters/optimizers at the same time.
Avoid random "FPS booster" executables and registry-cleaner packs.
Make a Windows restore point before system tweaking.
Back up important files before BIOS/CPU/RAM/GPU overclocking.
Never copy an overclock from another PC without testing stability.
Monitor CPU/GPU temperatures and voltage.
Use OCCT/Prime95/MemTest86 or similar tools to test stability.
DDU is normally used when changing/reinstalling graphics drivers, not as a routine daily optimizer.
Windows Defender should not be disabled just for gaming FPS.
Registry cleaning usually provides little useful performance benefit and can cause problems.
BIOS/UEFI firmware updates should use the motherboard manufacturer's official tool.
Prefer official developer websites/GitHub repositories for downloads.
