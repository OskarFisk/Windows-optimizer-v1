# Windows Optimizer v1

A Windows 11 desktop/laptop optimization and maintenance toolkit.

## Planned features
- Safe Windows 11 debloating with preview, exclusions, restore-point support and rollback where possible.
- Gaming, Balanced and Laptop/Battery optimization profiles.
- CPU, GPU, RAM, disk, network, temperatures and component monitoring.
- Conservative RAM cleanup and cache/temporary-file cleanup.
- Startup/background-app management.
- Integrated Programs Library with categories, search, official links and install guidance.
- Tool integrations for MSI Afterburner, AMD Ryzen Master, Intel tuning utilities, AMD/NVIDIA GPU tools and BlueStacks.
- Administrator elevation for tasks that genuinely require it.
- Desktop and laptop only; no mobile/tablet target.

## Safety
The app must not silently disable security software, Windows Update, firewall protections, Defender, or other critical protections. It must not automatically apply unsafe voltage/clock changes. Hardware-tuning utilities are integrations/launchers; users remain in control of overclocking.

Third-party installers are not redistributed by this project. The Programs Library should point to official vendor download pages and, where practical, use documented package managers.
